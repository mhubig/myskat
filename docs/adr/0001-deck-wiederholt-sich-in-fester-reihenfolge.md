# Deck wiederholt sich in fester Reihenfolge statt neu zu mischen

Ist das 32er-Deck vor Ablauf der 10 Minuten durchgespielt, beginnt die nächste Deck-Runde in **derselben Reihenfolge** — es wird nicht neu gemischt. Das wirkt wie ein Bug, ist aber Absicht: Das Tool bildet das Verhalten mit echten Karten ab, und dort hat mitten im AMRAP niemand Zeit, neu zu mischen. Gemischt wird genau einmal, automatisch beim Start des Workouts.
